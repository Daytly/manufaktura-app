Мануфактура — мини-приложение и отправка броней в ReMarked

Локальный запуск из папки проекта:
  python3 -m venv .venv
  .venv/bin/pip install -r requirements.txt
  .venv/bin/python server.py --check-remarked
  .venv/bin/python server.py
Адрес: http://127.0.0.1:8080
Логин и пароль читаются из .env. Проверка --check-remarked не создаёт броней.

Как работает:
Форма -> POST /api/bookings -> вход в кабинет -> создание брони в ReMarked.
Вход сначала разрешает перенаправление cabinet.clientomer.ru на региональный
сервер, а затем отправляет учётные данные непосредственно туда.
Заявка создаётся со статусом «Новая», источником Telegram, без назначения стола.
Подтверждение и выбор стола остаются за администратором. Сообщения гостю не
отправляются автоматически. Длительность берётся из настроек заведения.
Время считается по Барнаулу. Выбор 01:00 для вечера 23 октября передаётся как
24 октября 01:00. Успех показывается только после возврата номера брони.
Повтор одной заявки использует тот же operationId; запрос хранится в закрытой
SQLite-базе .private/bookings.sqlite3. После ошибки повторяйте те же данные.

Размещение:
Нужен Python-сервер с HTTPS, а не только статический хостинг/GitHub Pages.
Пример запуска за HTTPS reverse proxy (один процесс, несколько потоков):
  .venv/bin/gunicorn --workers 1 --threads 4 --timeout 120 --bind 127.0.0.1:8080 server:app
Укажите PUBLIC_ORIGIN=https://ваш-домен в .env; прокси должен сохранять Host.
Направляйте все запросы сайта на приложение. Не публикуйте корень проекта
через autoindex или отдельный статический сервер: там находятся .env и .private.
Приложение отдаёт только разрешённые публичные файлы. Сохраните .private при
обновлении/перезапуске: там находится журнал повторных отправок. Ограничитель
запросов использует адрес непосредственного клиента; за прокси настройте также
ограничение по IP на самом прокси. Не открывайте служебный порт наружу.
После размещения укажите HTTPS-адрес в настройках мини-приложения Telegram.

Ограничения:
Используется внутренний API кабинета, проверенный по коду его интерфейса
22.10.2026; изменения ReMarked могут потребовать обновления адаптера.
Интерактивный одноразовый код входа не поддерживается серверным адаптером.
Реальное создание тестовой брони отдельно от проверки входа не выполнялось.

Проверки:
  .venv/bin/python -m unittest discover -s tests -v
